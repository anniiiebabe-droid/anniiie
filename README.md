# 先吃 FIRST BITE

一款可直接导入微信开发者工具的原生微信小程序课程展示项目。它使用本地 Storage 管理食材库存、使用记录、令令成长、装扮和周报，无需后端或外部 API。

## 运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本仓库根目录。
3. AppID 可使用测试号；项目自带 `touristappid` 配置。
4. 编译后从首页开始操作。

## 推荐演示流程

1. 首页点击“快速添加食材”，添加 1 个洋葱，建议日期选今天。
2. 回到首页查看今日优先列表；点击“墨水屏”查看同步结果。
3. 点击洋葱的“使用”，确认全部用完，获得 10 XP、5 星星和紫色养料。
4. 进入“令令 → 积分商城”，用 5 星星兑换番茄帽。
5. 进入衣柜穿戴番茄帽。
6. 进入“我的 → 每周报告”查看本次操作生成的真实统计。

## 数据与安全说明

- “建议优先使用日期”由用户自行设置，仅用于排序。
- 超过建议日期的食材显示“请检查”，产品不判断或声称判断食品安全。
- 完成奖励以交易记录防重；撤销完成记录时同步回滚库存、XP、积分与养料。
- `services/device-service.js` 是未来接入真实墨水屏的接口边界。
