# 先吃 FIRST BITE

一款可直接导入微信开发者工具的原生微信小程序课程展示项目。它使用本地 Storage 管理食材库存、食用记录、令令成长、装扮和周报，无需后端或外部 API。

新版支持本地食材知识库自动分类，并根据购买日期、食材类型和储存位置估算建议食用日期；拍照识别为课程演示流程，已经为未来接入视觉识别服务预留交互入口。

## 运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本仓库根目录。
3. AppID 可使用测试号；项目自带 `touristappid` 配置。
4. 编译后从首页开始操作。

## 推荐演示流程

1. 首页点击“快速添加食材”，输入洋葱或体验拍照识别。
2. 系统自动填入分类、单位，并计算建议食用日期。
3. 回到首页查看优先列表；点击“墨水屏”查看令令与提醒文案。
4. 点击洋葱的“食用”，确认全部吃完，获得 10 XP、5 星星和紫色养料。
5. 进入“令令 → 积分商城”，用 5 星星兑换番茄帽。
6. 进入衣柜穿戴番茄帽，并观察令令的情绪动画。
7. 进入“我的 → 每周报告”查看本次操作生成的真实统计。

## 数据与安全说明

- “建议食用日期”由购买日期、食材知识库和储存位置估算，仅用于提醒与排序。
- 超过建议食用日期的食材显示“请检查”，产品不判断或声称判断食品安全。
- 完成奖励以交易记录防重；撤销完成记录时同步回滚库存、XP、积分与养料。
- `services/device-service.js` 是未来接入真实墨水屏的接口边界。
